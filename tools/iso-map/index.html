3D model

The same scene as the drawing, in metres: ground, a base you can 3D-print, buildings with domes, roofs and minarets. The site point is at 0, 0 and north is +Y (OBJ is Y-up, so north is −Z there). OBJ Rhino, Blender, SketchUp. DXF 3D faces on layers, plus streets, green, water and trees as lines and points, for AutoCAD and Rhino. STL 3D printing.

Data © OpenStreetMap contributors. Heights come from OSM tags where they exist; the rest are estimated, so treat this as an illustration, not a survey. Click a label in the drawing to hide it.
